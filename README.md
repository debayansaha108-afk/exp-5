# Experiment 5 – Android UI Development

## 📌 Description

This experiment is developed using Android Studio as part of the Mobile Application Development Lab. It focuses on Android application development, user interface design, and the implementation of interactive components.

The experiment provides practical experience in designing application layouts, writing application logic, and understanding how Android UI components work together to create a functional mobile application.

## 👨‍💻 Author

- **Name:** Debayan Saha
- **Subject:** Mobile Application Development Lab
- **Repository:** exp-5

## 🚀 Features

- Implements Android application functionality.
- Uses XML layouts to design the user interface.
- Uses Kotlin or Java for application logic, depending on the implementation.
- Demonstrates Android UI development concepts.
- Provides a practical example of mobile application development.

## 🛠️ Technologies Used

- Android Studio
- Kotlin / Java
- XML
- Android SDK
- Gradle
